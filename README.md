TreeGPT — Branching LLM System
A non-linear chat platform where conversations branch into multiple decision paths instead of a single thread.

* React + TypeScript + TanStack Router
* Supabase (Auth, Postgres, RLS for multi-user isolation)
* Edge Functions (Deno) orchestrating LLM workflows
* OpenRouter integration with fallback routing
* Built structured modes: chat / branching / summarization
* Focus on stateful workflows and reliable LLM outputs
